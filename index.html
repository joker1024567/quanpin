全拼只学四件事

全拼输入只要会这四件事。

一、V 键 = ü

键盘上没有 ü 这个键。用 V 输入。

nv女 nǚ
lv绿 lǜ
ve月 yuè（j/q/x + u 系统自动补 ü 点，不用 V）

只有 n 和 l 后面的 ü 必须打 V，其它按系统默认。

二、隔音符 '

两个音节连着打时，用撇号 ' 切开。

xi'an西安（不打 → "线"）
kuai'er快儿
dong'ao东奥

三、选字键

候选字出现后，四种按键：

← → ↑ ↓方向键换字（在候选间左右上下切换）
1–9数字键上字（直接选第 N 个候选）
Space空格键上字（默认选第一候选）
Enter不上字，原样上拼音（输入框出现"nv"，不变成"女"）

四、特殊符号 / emoji 内置输入

搜狗输入法自带两块面板。

① 特殊符号输入器

Ctrl + Shift + B搜狗输入法 符号大全面板（搜"勾选箭头""★""√"直接上屏）
a e o i u ü注音字母 ā ē ō ī ū ǖ（直接打 aeiou 全拼 → 候选框第 N 位 = 带音调注音符号）
v → 候选框直接打出字符 ü（不接拼音时）

② emoji 输入器

右键候选框搜狗输入法 emoji 面板（😀 👍 🎉 ❤️ — 直接点选上屏）

不需要背，输入法已经替你做完了。
