全拼只学四件事

全拼输入只要会这四件事。

一、V 键 = ü

键盘上没有 ü 这个键。用 V 输入。

nv女 nǚ
lv绿 lǜ
ve月 yuè（j/q/x + u 系统自动补 ü 点，不用 V）

只有 n 和 l 后面的 ü 必须打 V，其它按系统默认。

二、隔音符 '

两个音节连着打时，用撇号 ' 切开。

xi'an西安（不打 → "线"）
kuai'er快儿
dong'ao东奥

三、选字键

候选字出现后，四种按键：

← → ↑ ↓方向键换字（在候选间左右上下切换）
1–9数字键上字（直接选第 N 个候选）
Space空格键上字（默认选第一候选）
Enter不上字，原样上拼音（输入框出现"nv"，不变成"女"）

四、特殊符号 / emoji 内置输入

系统输入法自带的两个常用面板。

Win + .Windows 11 emoji 面板（搜狗/微软/QQ 输入法通常右键候选框 → emoji/符号）
Ctrl + Shift + B搜狗/QQ 输入法 符号大全面板（搜"勾选箭头""★""√"直接上屏）
右键候选框多数输入法有"emoji/表情/符号"入口

不需要背，输入法已经替你做完了。
